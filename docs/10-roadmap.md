# Roadmap — Painel Administrativo

## Estado Actual

### ✅ Implementado

- Autenticação Firebase com verificação de role admin
- Dashboard home com métricas do dia
- Gestão completa de motoristas (aprovação, documentos, corridas)
- Gestão de passageiros com detalhes de viagem
- Histórico de corridas com side panel (drawer)
- Visualização de rotas no mapa (Leaflet)
- Breakdown financeiro por corrida
- Visualização de imagens de prova (pickup/dropoff)
- Timeline de corridas
- Gestão de finanças — wallets e transações
- Exportação de relatórios (Excel + PDF)
- Sistema de missões para motoristas
- Envio de notificações push via API Fastify
- Logs de auditoria
- Configuração de tarifas (RideRates)

### 🔧 Em Progresso / Planeado

| Gestão de promoções / cupões                      | Alta       |
| Painel de controlo de fraudes                     | Alta       |
